# וייטנאם 2026

אפליקציית הטיול המשפחתי. אתר סטטי, בלי שרת ובלי תלויות חיצוניות.

**כתובת:** https://lalomavi-collab.github.io/vietnam2026/

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — עיצוב, תוכן ולוגיקה בקובץ אחד |
| `sw.js` | Service worker — מה שגורם לאפליקציה לעבוד בלי אינטרנט |
| `manifest.webmanifest` | הגדרות ההתקנה למסך הבית |
| `fonts/` | הפונטים, מאוחסנים מקומית כדי שיעבדו גם אופליין |
| `icons/` | האייקון של האפליקציה |
| `robots.txt` | מונע מגוגל לאנדקס את הדף |

## שינויים נפוצים

**להחליף את הקוד המשפחתי** — ב-`index.html`, לחפש:

```js
const FAMILY_CODE = 'PHO2026';
```

**לבטל את מסך הקוד לגמרי** — למחוק את הקריאה `initGate();` בסוף `index.html`.

**להסתיר שמות מלונות** — שמות המלונות מופיעים בשדה `hl` של הימים 1, 4, 10 ו-14 במערך `DAYS`.

**התוכן של הימים** — הכול במערך `DAYS` בתוך `index.html`: כותרת, שעות, "מגניב לדעת", המשימה הסודית, שמות קבצי התמונות מוויקימדיה, וקישור המפה.

## אחרי שינוי

1. לדחוף לענף `main` — GitHub Pages מפרסם תוך דקה.
2. **חשוב:** אחרי כל שינוי בקוד, להעלות את המספר ב-`sw.js`:

```js
const VERSION = 'v1';   // ← v2, v3...
```

בלי זה טלפונים שכבר פתחו את האפליקציה ימשיכו לראות את הגרסה הישנה מהמטמון.

"לשמור את הטיול בטלפון?" — לחיצה עליו מורידה את כל 54 התמונות למטמון הדפדפן.
