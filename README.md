# וייטנאם 2026

אפליקציית הטיול המשפחתי. אתר סטטי, בלי שרת ובלי תלויות חיצוניות.

**כתובת:** https://lalomavi-collab.github.io/vietnam2026/

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — עיצוב, תוכן ולוגיקה בקובץ אחד |
| `sw.js` | Service worker — מה שגורם לאפליקציה לעבוד בלי אינטרנט |
| `manifest.webmanifest` | הגדרות ההתקנה למסך הבית |
| `fonts/` | הפונטים, מאוחסנים מקומית כדי שיעבדו גם אופליין |
| `icons/` | האייקון של האפליקציה |
| `robots.txt` | מונע מגוגל לאנדקס את הדף |

## שינויים נפוצים

**להחליף את הקוד המשפחתי** — ב-`index.html`, לחפש:

```js
const FAMILY_CODE = 'PHO2026';
```

**לבטל את מסך הקוד לגמרי** — למחוק את הקריאה `initGate();` בסוף `index.html`.

**להסתיר שמות מלונות** — שמות המלונות מופיעים בשדה `hl` של הימים 1, 4, 10 ו-14 במערך `DAYS`.

**התוכן של הימים** — הכול במערך `DAYS` בתוך `index.html`: כותרת, שעות, "מגניב לדעת", המשימה הסודית, שמות קבצי התמונות מוויקימדיה, וקישור המפה.

## שלוש תכונות לבני נוער

נבנו בתוך אותו `index.html`, בלי ספריות או שלב build, ולכן עובדות אופליין כמו כל השאר:

| טאב | קובע התוכן שלו |
|---|---|
| 🧭 **סקר סודי** | `RADAR_SPOTS`/`RADAR_CATS` — מקומות לא-תיירותיים לפי קטגוריה, עם סינון תקציב/פתוח-עכשיו ומיון לפי מרחק (GPS חי כשמאושר, אחרת `distanceMeters` הקבוע בנתונים) |
| 💰 **כסף** (הורחב) | `RESULTS` (ההמרה המקורית) + בדיקת מיקוח (`bargAsk`/`bargTarget`) + יומן הוצאות אישי (`state.budget`, קטגוריות ב-`EXP_CATS`) |
| 🎧 **פסקול** | `MUSIC_MODES` — שלושה מצבים, כל אחד סולם/טמפו/גוון צליל משלו. אין קבצי מוזיקה מורשים לשימוש שאפשר לצרף לריפו; זה מנוע Web Audio גנרטיבי קטן (אותם `note()`/`ac()` שמפעילים את כפתור המוזיקה בכותרת), ולכן גם הוא עובד בלי אינטרנט |

## כרונו-לנס 🕰️

כפתור בכל יום ("🕰️ כרונו-לנס") שפותח מפגש עם דמות אחת לכל אזור טיול — מוגדרות ב-`CHRONO`
(מפתח לפי `d.region`, אותו שדה שכל יום כבר נושא). כל דמות מתויגת בכנות: `kind:'history'`
(אדם ואירוע מתועדים), `kind:'legend'` (אגדה ידועה, לא היסטוריה), או `kind:'rep'` (דמות
מייצגת של קהילה אמיתית, לא אדם ספציפי) — התיוג מוצג גם למשתמש כ-`tag`. יש מצלמה חיה
(`getUserMedia`, עם נפילה חזרה מלאה לגרדיאנט כשאין הרשאה/מצלמה) עם סליידר "מסע בזמן"
שמדרג את הצבע מ־sepia ישן לצבע מלא, מערכת שאלות-תשובות קבועה מראש, ושלוש משימות
צילום לכל דמות שנשמרות ב-`state.chronoDone`. כפתור "לתעד את הרגע" לא בונה צנרת שמירה
חדשה — הוא קורא ל-`shoot()` הקיים עם כיתוב מוצע, כך שהתמונה נכנסת ישר לאלבום/לסרט/לחוברת
כמו כל תמונה אחרת בטיול.

2. **חשוב:** אחרי כל שינוי בקוד, להעלות את המספר ב-`sw.js`:

```js
const VERSION = 'v1';   // ← v2, v3...
```
